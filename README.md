# Maou

> Code. Automate. Iterate.

A quiet, type-led corner of the internet for **Maou** (Musa Usman) — a creative
developer based in Nigeria.

that opens like a curtain. Nothing borrowed, nothing loud. Just a place to think
out loud and put the work somewhere it can breathe.
